# 📚 Book Alchemy - Book Store Application

A modern full-stack web application that allows users to browse, search, and interact with a curated list of free and paid books.

## 📌 Overview

Book Alchemy is a MERN-based (MySQL, Express, React, Node) project built to provide:
- A smooth user experience for book discovery
- Authentication and authorization
- Visual UI using TailwindCSS and DaisyUI

---

## 🧩 Features

- 📖 **Dynamic Book Display** – Explore books by categories, images, titles, and prices  
- 🛒 **Buy Now** – Add books to your cart instantly  
- 🔍 **Search Functionality** – Find books using titles or keywords  
- 🧑‍💻 **Login / Signup** – Authenticated access and session handling  
- 🌐 **Responsive Design** – Built with Tailwind and DaisyUI  
- 🧠 **Semantic UI** – Clean visual layout with semantic HTML and reusable components

---

## 🧑‍💻 How to Run Locally

```bash
# Clone the repository
git clone https://github.com/rohit22110423/Web-Development-Project.git
cd Web-Development-Project

# Install backend dependencies
cd backend
npm install

# Start backend server
node index.js

# In a new terminal: install frontend dependencies
cd ../frontend
npm install

# Start frontend
npm run dev
